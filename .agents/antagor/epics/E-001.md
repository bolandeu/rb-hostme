## Problem

Five .md files were written before the doc kinds existed. The gate refuses a new .md outside the four kinds, and these five keep the project outside that rule.

## Goal

Every tracked .md of hostme is one of the four kinds: layout check lists no docs to sort, and no content of an old doc is lost

## Acceptance (Given–When–Then)

- Given the five docs PRD.md, TODO.md, WILDCARD-SSL.md, docs/surge-cli.md, docs/webinoly.md, when the epic closes, then antagor layout check reports no docs to sort
- Given a doc that is not living, when its task ends, then its report lists each section and where it went: an idea, an ADR, a research record or a living doc

## Implementation decisions

- Each doc is declared in [docs] in antagor.toml when it is living, or its content moves out and the file goes

## Out of scope

- Editing living docs beyond what sorting needs
- Dropping any doc without the Human's yes
