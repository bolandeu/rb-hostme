## Problem

PRD.md, TODO.md, WILDCARD-SSL.md, docs/webinoly.md and docs/surge-cli.md are plans, backlogs and notes kept as files, so the layout check refuses them and they drift from the code.

## Goal

Every tracked .md is one of the four kinds; `antagor layout check` has nothing to sort; every section of the five old docs has a destination (an idea, an ADR, a research record, a living doc) or the Human's yes to a drop.

## Acceptance (Given–When–Then)

- Given the five docs to sort, When all three tasks are done, Then `antagor layout check` lists nothing to sort.
- Given any section of an old doc, When that task's report is read, Then the section is in an idea, an ADR, a research record, a living doc, or listed as a drop with the Human's yes.

## Out of scope

- No code or CLI behaviour change.
- No new feature work from the sorted material; the ideas wait in the list.
