## Problem

Two servers can claim the same base domain and nothing says which one wins; the agent contract promises no questions, JSON and sane exit codes, but no run from a TTY-less shell is recorded.

## Goal

The rule that picks a server for an ambiguous domain is decided, tested and written down; the agent contract has a record of a real non-TTY run with its exit codes.

## Acceptance (Given–When–Then)

- Given two servers claiming one base domain, When a deploy resolves the server, Then the rule is stated in an ADR and covered by a unit test.
- Given a shell without a TTY, When the listed commands run, Then the doc records the answers and the exit codes.

## Out of scope

- Any change to the resolution rule beyond the ambiguity case.
