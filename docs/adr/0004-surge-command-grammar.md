# Форма команд — как у surge.sh

CLI повторяет грамматику surge.sh: `hostme <path> [domain]` — деплой (без слова
`deploy`), `hostme <domain> <subcommand>` — управление сайтом, домен первым.
Свой стиль команд hostme не изобретает.

Причина: привычка уже есть — `surge <path> <domain>`, `surge <domain> teardown`.
Доменные команды у surge — «домен первым», и путать этот порядок с обычным
`hostme teardown <domain>` дороже, чем один переходник. Совпадающая грамматика
ещё и даёт готовый справочник для сверки: что реально есть у surge, hostme
копирует, а не додумывает.

Следствия:

- `Typer`/`Click` рисует в `Usage` обратный порядок аргументов; правду говорит
  первая строка docstring команды — её проверяет гейт по реальному переводу
  argv (`_translate_argv` в `cli.py`).
- Команды аккаунта surge (`login`, `whoami`, `plan`, `card`, `mfa`, `tokens`,
  `invite`, `revoke`, `stats`, `nuke`) не переносятся: у hostme один
  пользователь и своя инфраструктура.
- Что surge не умеет и добавил hostme: серверы и base-домены (`server`,
  `domain`), `--server` для первого деплоя собственного домена, target'ы
  (сторонние хостинги).
