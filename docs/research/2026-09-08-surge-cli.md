# Форма команд surge.sh

Дата: 2026-09-08. Откуда: http://surge.sh/docs/cli/. Зачем: `hostme` намеренно копирует форму команд surge — `<path> <domain>` для деплоя, `<domain> <подкоманда>` для управления (решение — ADR 0004). Здесь сохранён список того, что у surge реально есть, для сверки при реализации новых команд.

Статус: выжимка, полный список флагов в неё не входил.

## Публикация

- `surge <path> <domain>` — задеплоить проект на домен.
- `surge <path> publish` — задеплоить по `CNAME`-файлу проекта.
- `surge ... --preview` — деплой-превью, продакшн не меняется.

## Управление проектом

- `surge <domain> revs` — история версий.
- `surge <domain> rollback` / `rollfore` / `cutover` / `discard` — переключение между версиями.
- `surge <domain> config` — просмотр и изменение настроек проекта.
- `surge <domain> teardown` — снести опубликованный проект.
- `surge <domain> invite <emails>` / `revoke <emails>` — совместный доступ. Не переносим: `hostme` на одного пользователя.

## Инфраструктура и мониторинг

- `surge <domain> dns` / `zone` — управление DNS-записями.
- `surge <domain> stats` — трафик и аналитика. Не переносим.
- `surge <domain> debug` — статус, файлы, аудит-логи, кэш, сертификаты.
- `surge <domain> ssl` — установка своего сертификата.

## Аккаунт

`login` / `logout` / `whoami` / `verify` / `mfa` / `list` / `plan` / `card` / `tokens` / `nuke`. Не переносим: у `hostme` своя инфраструктура, нет аккаунта и биллинга. Из группы остаётся только смысловой аналог `list` — список сайтов.

## Что осталось несверенным

Полный Command Reference surge в выжимку не попал. Флаги подкоманд `config`, `debug`, `ssl` сверить там, когда эти подкоманды дойдут до реализации.
