# Контракт для агента

Что агент получает от hostme и на что может рассчитывать. Встроенная копия этого
контракта для чужих проектов — `src/hostme/data/SKILL.md` (`hostme --ai` печатает
её, `hostme skill install` кладёт в `~/.claude/skills/hostme/`).

## Проверка, а не догадка

Команды hostme не задают вопросов по умолчанию — кроме подтверждения
деструктивного действия. Неинтерактивный вызов — правило, а не режим:

1. `--json` в любой позиции (до и после команды) — чистый JSON в stdout, без
   цвета и лишних строк.
2. `--non-interactive` — никогда не спрашивать; если подтверждение нужно, команда
   падает с понятной ошибкой, а не ждёт.
3. `--dry-run` — показать, что сделала бы деструктивная команда, ничего не меняя.
4. `--confirm` (алиас `--yes`, `-y`) — единственный способ пройти гейт
   подтверждения без TTY. `teardown`, `rollback`, `maintenance` требуют его.
   Деплой и `teardown` на target требуют `--confirm` на **каждый** вызов, и
   `--json` его не пропускает молча: агент передаёт `--confirm` только по явному
   «да» человека на это действие.

## Коды возврата

| Код | Значение |
| --- | --- |
| 0 | успех |
| 1 | общая ошибка, а также `ABORTED` и `UNEXPECTED` |
| 2 | неверные аргументы |
| 3 | проблема с доступом (`auth status`: доступ не в порядке) |
| 4 | проект не инициализирован |
| 5 | ошибка провайдера: сеть, таймаут, 5xx/429, ssh/rsync/lftp/Webinoly |

Таблица — из `core/errors.py` (`EXIT_CODES`), её же печатает
`hostme describe --json`. Код не дублируется здесь: здесь его смысл для агента.

## Конверт ошибки

Под `--json` любая ошибка приходит в stdout одним объектом:

```json
{"ok": false, "error": {"code": "PROVIDER_ERROR", "message": "…", "action": "…"}}
```

`action` — что сделать дальше. Голых стектрейсов наружу нет: непредвиденное
исключение тоже становится конвертом `UNEXPECTED`.

## Откуда взять список команд

Список команд руками не переписывается. Источники:

- `hostme` — команды с первой строкой описания;
- `hostme help` — полный справочник с реальным порядком аргументов;
- `hostme help --json` и `hostme describe --json` — то же машиночитаемо.

## Форма команд

Грамматика скопирована у surge.sh и не совпадает с обычным `Typer`/`Click`:
`hostme <path> [domain]` — деплой, `hostme <domain> <subcommand>` — управление
сайтом (домен первым). Первая строка описания команды показывает её реальную
форму вызова. Почему так — ADR [0004](../adr/0004-surge-command-grammar.md).
