
 Usage: hostme debug [OPTIONS] {domain}

 hostme <domain> debug [--error] [--lines N] — HTTP-статус сайта + хвост nginx-лога с сервера.

 Example: hostme landing.example.com debug --error --lines 50

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    domain      <str>  Домен сайта из `hostme list`. [required]                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --error                 Хвост error-лога вместо access-лога.                                     │
│ --lines          <int>  Сколько строк лога. [default: 10]                                        │
│ --help   -h             Show this message and exit.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
