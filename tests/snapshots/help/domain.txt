
 Usage: hostme domain [OPTIONS] COMMAND [ARGS]...

 Служебные (base) домены — для авто-генерации поддоменов при деплое.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --help  -h        Show this message and exit.                                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ add      hostme domain add <server> <domain> [--default] — зарегистрировать служебный домен.     │
│ default  hostme domain default <domain> — сделать служебный домен дефолтным.                     │
│ remove   hostme domain remove <domain> — убрать служебный домен из реестра (сайты на нём не      │
│          трогаются).                                                                             │
│ list     hostme domain list — служебные домены и какой сервер за каждым стоит.                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
