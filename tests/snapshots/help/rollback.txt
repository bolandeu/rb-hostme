
 Usage: hostme rollback [OPTIONS] {domain}

 hostme <domain> rollback [--confirm] — откатить на предыдущий релиз (сервер) или последний
 локальный бэкап (target).

 Обратимо: на сервере это переключение symlink (`rollfore` вернёт обратно),
 на target — восстановление снепшота, снятого перед последним деплоем.
 --dry-run показывает, на какой релиз откатился бы.

 Example: hostme landing.example.com rollback --confirm

│ *    domain      <str>  Домен сайта из `hostme list`. [required]                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --confirm,--yes  -y        Подтвердить деструктивное действие без вопроса (обязателен вместе с   │
│                            --non-interactive/--json).                                            │
│ --help           -h        Show this message and exit.                                           │
