
 Usage: hostme server [OPTIONS] COMMAND [ARGS]...

 Управление серверами (свои VPS с Webinoly).

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --help  -h        Show this message and exit.                                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ add     hostme server add --name N --host H [--user U] [--key PATH] [--default] —                │
│         зарегистрировать сервер.                                                                 │
│ init    hostme server init <name> — поставить (или проверить) Webinoly на сервере.               │
│ update  hostme server update <name> — обновить сам Webinoly на сервере (не системные пакеты).    │
│ list    hostme server list — все зарегистрированные серверы (имя, user@host, default).           │
│ remove  hostme server remove <name> [--force] — убрать сервер из локального реестра.             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
