
 Usage: hostme skill install [OPTIONS]

 hostme skill install [--path PATH] — записать встроенный SKILL.md туда, откуда его читает
 AI-агент.

 Источник правды — копия внутри установленного пакета (`hostme --ai` печатает
 её же); после обновления hostme перезапусти, чтобы установленный skill не
 расходился с реальным CLI.

 Example: hostme skill install

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --path          <str>  Куда записать (по умолчанию — ~/.claude/skills/hostme/SKILL.md).          │
│ --help  -h             Show this message and exit.                                               │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
