
 Usage: hostme target [OPTIONS] COMMAND [ARGS]...

 Сторонние хостинги (ftp/sftp/ssh, без Webinoly) — только заливка файлов.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --help  -h        Show this message and exit.                                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ add     hostme target add --name N --connection ssh|ftp|sftp --host H --user U [--password P]    │
│         [--ssh-key PATH] [--path REMOTE] — зарегистрировать сторонний хостинг.                   │
│ list    hostme target list — зарегистрированные target'ы (без паролей — только факт их наличия). │
│ remove  hostme target remove <name> [--force] — убрать target из реестра и его пароль из         │
│         keychain.                                                                                │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
